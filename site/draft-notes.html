Draft notes

About this draft

This is a public draft of the Latch project site for feedback. The compiler package is not yet public.

Publication status

The documentation describes the prepared research-preview package, megakernel-lab 0.9.0rc1. Its source, installable packages and original-code license will be published separately. This website repository contains only the site and public measurement summaries.

Package scope

The prepared package includes the operation compiler, fast examples, TinyMoE training adapter, selective-update and looped-model examples, and the GradLev adaptation example. Support and numerical qualification apply to the exact configurations listed in the workload catalogue. The private four-H100 MoE runner and experimental MoRE, DeltaTTT and general distributed-training paths are excluded.

Command guides

The installation and example commands describe the prepared package. They require that package and cannot be run from this website repository alone. Complete example scripts and reproduction guides will accompany the compiler release.

Validation summary

The final package passed clean wheel and source-distribution installation, installed-example checks, H100 numerical and restart checks, and the recorded compiler tests (2,269 passed; 12 known pre-existing failures remain). Validation is bounded to the tested programs, shapes, states and numerical policies; it does not establish arbitrary-model support or long-training equivalence for changed code.

The TinyMoE example includes fresh and trained-state checks, exact repeat and restart checks, and independent FP64 audits at updates 1 and 32. GradLev includes carried-state, reset, restart and held-out block comparisons. The earlier v0 records shown on the site are historical measurements of their original runtime, not requalification of changed code.

See the source tables, methodology and final-package measurement summary for the measured scopes and limits.

Learning studies

The training-to-quality comparison uses an earlier compiler and is separate from the current update-speed measurements. The original 62.5%-fewer-tokens pilot did not establish a general advantage after stronger schedule comparisons; its follow-ups are preserved in the study history.

Evidence availability

The public JSON files contain measurement summaries. Full release manifests, internal source paths, worker identifiers, raw receipts, binaries and checkpoints are retained privately and are not included in this draft repository. Numerical values and stated limitations have not been changed for this website deployment.
