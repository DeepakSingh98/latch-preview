The evidence files below contain measurements, source commits and hashes. Full reports and reproduction instructions will accompany the open-source code.

Measurement labels
  • Pilot A single-seed study. Follow-up experiments did not confirm the small-batch pilot’s advantage.
  • Research branch A study on a separate compiler branch. Its workload is not included in the installed package.
  • Requalification pending Built with the rowchain rule before its arena race was fixed. The program needs to be rebuilt and checked.
  • Computed Calculated from published specifications or parameter counts.
  • In this package Measured with package 0.9.0rc1. Each record gives the timing and checks performed.
  • Verified in v0 checks of the earlier v0 rc2 package (0.8.0rc1).
  • Historical An earlier delivery or study. Its checks apply to the binaries measured.
  • Qualified The measured binaries passed the stated numerical checks at the tested states.
  • Measured Timing is recorded. The accompanying numerical checks are described in the record.
