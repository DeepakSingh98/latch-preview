Where the numbers come from

Each number on this site maps to a measurement or a stated calculation below. Schematic diagrams carry no measured values. The linked JSON files are public measurement summaries. Internal file locations and worker identifiers are omitted from this draft. The original receipts, binaries and checkpoints remain in private storage.

The final v0 package, megakernel-lab 0.9.0rc1, has completed the bounded qualification listed first. The v0 rc2 package (0.8.0rc1), release candidate 0.7.1rc1 and donor measurements are retained separately as history; their qualification does not transfer to changed runtime bytes. The source manifest and runtime-custody records are retained privately with the release; see evidence availability.

Status labels

  • Pilot single seed. The small-batch pilot was later not confirmed; see the learning studies below.
  • Research branch a later study on a research compiler branch; not an installed-package capability and no v0 qualification.
  • Requalification pending built with the rowchain compiler rule, later found to permit an arena race; rebuild and re-check before citing.
  • Computed arithmetic from published specifications or parameter counts, not a measurement.
  • In this package measured with the final package 0.9.0rc1, with numerical, restart and timing scope stated explicitly.
  • Verified in v0 checks of the earlier v0 rc2 package (0.8.0rc1).
  • Historical a prior delivery or study; any qualification applies only to those measured binaries.
  • Qualified passed the stated independent numerical checks for the exact binaries and states measured.
  • Measured measured as described; numerical checks narrower than qualification, as stated.
